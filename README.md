**Product Listing and Detail Page Project**

A React application that showcases a product listing page and a product detail page with add to cart and remove from cart functionalities.

**Overview**
This project demonstrates how to build a simple e-commerce application using React. The application consists of two main pages: a product listing page and a product detail page. Users can add products to their cart and remove them as needed.

**Features**
- Product Listing Page: Displays a list of products with images, names, and prices.
- Product Detail Page: Shows detailed information about a product, including description, price, and image.
- Add to Cart: Allows users to add products to their cart.
- Remove from Cart: Enables users to remove products from their cart.

**Requirements**
- Node.js
- npm or yarn
- React

**Usage**
1. Clone the repository.
2. Run npm install or yarn install to install dependencies.
3. Run npm start or yarn start to start the development server.
4. Open http://localhost:3000 in your browser to view the application.

**Code Structure**
The project consists of several components:

- ProductList.js: Displays the list of products.
- ProductDetail.js: Shows detailed information about a product.
- Cart.js: Manages the cart functionality.
- App.js: Handles routing and renders the main application.

**Component Details**
- ProductList.js:
    - Displays a list of products with images, names, and prices.
    - Links to the product detail page for each product.
- ProductDetail.js:
    - Shows detailed information about a product, including description, price, and image.
    - Allows users to add the product to their cart.
- Cart.js:
    - Manages the cart functionality, including adding and removing products.
    - Displays the products in the cart.

**Example Use Cases**
- Browsing products on the product listing page.
- Viewing detailed information about a product on the product detail page.
- Adding products to the cart.
- Removing products from the cart.
