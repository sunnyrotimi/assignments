**Shopping Cart Project**

A simple shopping cart application built in Python that allows users to add, remove, display, and quit the program.

Features
- Add Item: Prompts the user to enter an item to add to the cart.
- Remove Item: Prompts the user to enter an item to remove from the cart.
- Display Cart: Displays all items currently in the cart.
- Quit: Exits the program.

**Requirements**
- Javascript 

**Usage**
1. Run the program.
2. Choose an option by typing "add", "remove", "display", or "quit".
3. Follow the prompts to add or remove items from your cart.
4. Type "quit" to exit the program.

**Code Structure**
The project consists of a single javascript file (shopping_cart.js) that defines a ShoppingCart class. The class has methods for adding, removing, displaying, and quitting the program.

**Example Use Cases**
- Adding an item to the cart: Type "add" and enter an item name.
- Removing an item from the cart: Type "remove" and enter the item name.
- Displaying the cart: Type "display" to view all items in the cart.
- Quitting the program: Type "quit" to exit.
